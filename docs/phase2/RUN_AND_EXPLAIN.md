# Reproduce the experiments

Run the commands from the repository folder with the [Python environment from the README](../../README.md#run-the-saved-demo). The saved demo is available as soon as you run `python scripts/restore_results.py`.

## Phase 1 · Classical ML

```bash
python scripts/download_data.py
python masterNotebook.py
python run_tests.py --phase 1
```

The download script gets the official Corr2Cause train, development, and test splits. Phase 1 audits the data, extracts 28 features, trains the models, and writes the evaluation to `outputs/phase1/`. With the data and a completed training run in place, `python masterNotebook.py --evaluate-only` regenerates the evaluation using those trained models.

## Phase 2 · DistilBERT and the hybrid

Run Phase 1 first to create the feature cache and full-data comparison model.

```bash
python scripts/download_model.py
python phase2.py prepare
python phase2.py pilot
python phase2.py train --experiment main
python phase2.py train --experiment unweighted
python phase2.py train --experiment frozen --device cpu
python phase2.py evaluate
python run_tests.py
python phase2.py demo
```

- `prepare` selects whole premise groups, makes token windows, and trains the matched Random Forest.
- `pilot` times a training batch to estimate the compute needed.
- `train` runs one DistilBERT experiment. Use `--device cpu`, `--device mps`, or `--device cuda` to choose a device. Completed runs are reused unless you pass `--force`.
- `evaluate` uses the development set for thresholds and model selection, then measures classification and graph performance on the test set.

The saved [Phase 2 results](../../results/phase2/RESULTS.md) include the [split manifest](../../results/phase2/data_manifest.json), [classification scores](../../results/phase2/metrics.json), and [graph evaluation](../../results/phase2/graph_metrics.json). Model weights are generated by training and stored in `outputs/phase2/`.
